

# Projet : Systeme de recommandation E-commerce

Ce projet consiste en la mise en place d'une pipeline MLOps complète pour la prédiction des articles les plus achetés sur un site e-commerce.

## Description

L'objectif est d'automatiser le cycle de vie d'un modèle de recommandation, du prétraitement des données brutes jusqu'au déploiement. Le projet met l'accent sur la gestion de gros volumes de données et l'industrialisation des processus.

## Pipeline MLOps

* **Preprocessing :** Nettoyage et transformation des données de transactions.
* **Gestion des données :** Stockage et manipulation via Google Cloud Storage (GCP).
* **Tests :** Validation systématique des données et des performances du modèle.
* **Déploiement :** Automatisation du flux pour garantir une mise en production continue.

## Stack technique

* Langage : Python
* Cloud : Google Cloud Platform (GCP)
* Outils : Pipelines de données, MLOps, Big Data
